# triggers-finanzas

Gráficos y animaciones de los análisis que se publican en [@SomosMateria](https://x.com/SomosMateria).

Este repositorio existe por una razón técnica: la herramienta que programa las publicaciones descarga las imágenes desde una dirección pública, sin credenciales, en el momento de publicar. Por eso vive aparte y en abierto; el código y los datos del sistema de análisis están en otro sitio y son privados.

Aquí no hay análisis, ni código, ni datos de cartera: solo los archivos visuales que acompañan a cada publicación, con la misma fecha y el mismo nombre que el hilo al que pertenecen.

## Cómo se organiza

```
graficos/<AAAA-MM-DD>_<tema>/<archivo>.png|gif|mp4
```

## Uso de las imágenes

Se pueden citar y compartir indicando la fuente. Cada gráfico dice de dónde salen sus datos.
